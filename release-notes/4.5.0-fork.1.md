基于 macshot 4.5.0-beta.2，和官方版相比主要有这些改动：

- 新增资料库窗口，所有截图和录屏都在里面；历史面板里也能看到录屏
- 录屏可以存到其他磁盘
- 滚动截屏会认出不随页面滚动的顶栏和滚动条，不再把它们拼进长图；截屏时周围变暗，旁边实时显示拼好的长图
- 选区可以吸附到屏幕和前台窗口的中线，参考线上标出对齐的对象
- 工具栏跟随系统的浅色 / 深色外观，取色器和二级选项改用和工具栏一致的面板
- 设置窗口改成系统设置的样式
- 截图后的浮动缩略图改成卡片样式，点一下直接打开截图
- 截图和录屏存到同一个文件夹，共用一个文件名模板
- 新增上传到 GitHub
- 有新版本时发系统通知，在设置里更新，装好后自动重启
